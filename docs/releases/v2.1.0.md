## ⪩ Media Forge v2.1.0 ⪨

A found update now opens a sheet with its release notes and an Install button, instead of a small note in the
title bar.

---

### ⤷ Added ˎˊ˗

- **Update sheet** — when a newer version is found, a sheet opens over the window with the new version, the
  installed version, the size and the date of the release and its full release notes. **Install** downloads the
  update if it is not on disk yet and restarts the app as soon as the file is verified; **Later** closes the sheet
  until you click the version label in the title bar. With **Download updates automatically** on, the sheet shows
  the download progress and then **Restart to update**.

### ⤷ Changed ˎˊ˗

- The "new version available" toast is gone; the sheet is the notice. The "ready to install" toast still appears
  when a background download finishes while the sheet is closed.

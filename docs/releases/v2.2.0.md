## ⪩ Media Forge v2.2.0 ⪨

One compact design shared with the other apps: a new typeface, a tighter layout and a Scale setting for the whole window.

---

### ⤷ Added ˎˊ˗

- **Scale** — Settings > Appearance > **Scale** sets the size of the whole window and its text: 100, 125, 150, 175 or 200 % on top of the Windows display scaling. The window grows with the step and takes effect at once; on a small screen it keeps a layout step that still fits (down to 480 x 640 at 150 % and above).

### ⤷ Changed ˎˊ˗

- **Typeface** — the window is set in Sora with one fixed scale of text sizes; headings, labels, buttons and meta lines are each one size, so the same thing looks the same everywhere.
- **Compact layout** — smaller buttons, switches, segmented controls, fields, rows and cards; a 44 px title bar; the footer and the Start pill are 48 px.

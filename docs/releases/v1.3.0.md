## ⪩ Media Forge v1.3.0 ⪨

Update checks every five minutes and automatic download switched on by default.

---

### ⤷ Changed ˎˊ˗

- **Update check** — the app checks for a new version on launch and then every 5 minutes while it runs. A failed check is retried later with a growing wait of up to an hour, and no check is made without a network connection.
- **Download updates automatically** — now on by default. A copy that turned it off keeps it off; a copy that never touched it downloads new versions in the background from now on. A version downloaded in the background still installs only on **Restart**.

### ⤷ Removed ˎˊ˗

- **Check interval** — the setting is gone from the Updates group of the settings sheet; the value stored by earlier versions is ignored.

## ⪩ Media Forge v1.1.0 ⪨

A fixed window without the frame line, quicker file actions and the shared interface kit.

---

### ⤷ Added ˎˊ˗

- **Start now** — a file waiting in the queue can be started at once from its card, regardless of the "Files at the same time" setting.
- **Remove from the collapsed card** — a red trash button in every card header removes the file without opening its settings; a running file is cancelled first.

### ⤷ Changed ˎˊ˗

- **Fixed window** — the window keeps its 630 x 840 size (a smaller 3:4 size on small screens) and is no longer resizable; the light frame line at the top edge is gone.
- **Interface kit** — the glass material, controls, background and the version / update popover now come from the shared Liquid UI kit used by all apps of this account; nothing changes in how they work.

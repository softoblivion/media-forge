## ⪩ Media Forge v2.4.0 ⪨

Files open in Media Forge straight from Explorer, the window can be resized, animated WebP and PNG stay animated, and a new major version is an ordinary update again.

---

### ⤷ Added ˎˊ˗

- **Open from Explorer** — open files in Media Forge with **Open with**, **Send to** or by dropping them on `MediaForge.exe`. When the app is already open, the files join its list; when that window is just closing, the start waits for it and opens its own window with the files.
- **Resizable window** — drag any edge or corner to resize the window; it remembers its size and place for the next start. A wider window centres the list, a taller one shows more files.
- **Animated WebP and PNG** — animated WebP and animated PNG files stay animated, and both are new output formats next to GIF, labelled **WebP** and **APNG**. WebP and APNG outputs keep each frame's time and the number of plays; a GIF output keeps the number of plays and the total time, and a video keeps the total time.
- **Keep file dates** — on by default: each output gets its source's dates, so folders sorted by date stay in order.
- **Subfolders in one output folder** — a dropped folder brings the files of all its subfolders, and with one output folder the outputs keep the same subfolders. An output folder that lies inside the dropped folder is left out, so a second drop does not convert the outputs again, and a folder walk stops at 1000 media files with a notice.

### ⤷ Changed ˎˊ˗

- **New major versions** — a release with a new major version is found, downloaded in the background and installed on **Restart** like every other update. The **Switch** / **Stay** choice of 2.3.2 is gone.
- **Scale** — changing Scale keeps the window's proportions and its centre; steps too large for the screen are dimmed. A chosen step that no longer fits, after a change of display, is applied as the largest step that fits and comes back on a screen with room for it; the setting itself stays as chosen.
- **WebM audio** — a WebM output's Audio row says that it writes Opus.
- **Audio format labels** — M4A and OGG read as their format names; their tooltips name AAC and Vorbis.
- **Size limit with a kept audio track** — when the audio leaves the video too little room, it is re-encoded at a lower bitrate instead of the job failing, and the video gets the room it frees.
- **Video formats in two rows** — a video's formats show as a **Format** row (videos and animated images) and an **Audio only** row (MP3, M4A, Opus, FLAC, WAV) with one choice between them, so every option is in view at any window width. For a video without an audio track the Audio only row is dimmed.

### ⤷ Fixed ˎˊ˗

- **Start with a file** — `MediaForge.exe` closed at once when it was started with a file.
- **WAV depth** — WAV output keeps 24-bit, 32-bit and floating-point samples instead of turning them into 16-bit.
- **Animated GIF at start** — an animated GIF added in the first seconds after start no longer stays in an "ffmpeg is not available" error.
- **Parallel jobs** — raising **Files at the same time** after lowering it could run fewer jobs than set.
- **Quick settings changes** — changes made in quick succession could be saved out of order.
- **Photo orientation** — photos with kept metadata could show turned twice in viewers that read XMP.
- **Unfinished outputs** — a cancelled or failed job whose unfinished output another program (a virus scanner, a thumbnail viewer) held for a moment left that file behind; the job now tries again for about 3 seconds.
- **Cancel at the finish** — a job cancelled at the moment it finished went back to ready although its file had been written.
- **Ready update and no network** — a downloaded update no longer drops back to a plain notice when a later check finds no network or hits the GitHub limit.
- **Other displays** — moving the window to a screen with another display scaling keeps its size and sharp text, and dragging it by the title bar follows the mouse exactly at every Scale.

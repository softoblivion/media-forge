## ⪩ Media Forge v1.0.0 ⪨

First release: one portable exe that compresses, upscales and converts video, photo and audio files, each file with its own settings.

---

### ⤷ Added ˎˊ˗

- **Compress video** — H.264, H.265, AV1 (CPU, or NVIDIA NVENC when the machine has it), VP9 and ProRes; a quality slider or a size limit in MB that the output stays under (two-pass bitrate targeting with one corrective retry).
- **Compress photos and audio** — JPEG, WebP, AVIF, HEIC with a quality slider or a size limit (quality search, then a downscale ladder); MP3, AAC, Opus, OGG at a chosen bitrate or a size limit, with optional loudness normalisation.
- **Upscale 2x / 4x** — Lanczos resampling with a light sharpen, or a deterministic super-resolution network (FSRCNN bundled, EDSR downloaded once, 38 MB per scale). Same input, same output, nothing invented.
- **Convert** — MP4, MKV, WebM, MOV, GIF and audio extraction (MP3, M4A, Opus, FLAC, WAV); JPEG, PNG, WebP, AVIF, TIFF, BMP, HEIC; MP3, M4A, Opus, OGG, FLAC, WAV. Fit to 1080p / 720p / 480p, frame rate, audio track choice.
- **Clean outputs** — by default no EXIF, XMP, IPTC, chapters or encoder tags; the ICC profile is kept. The "Remove metadata" switch is per file.
- **Per-file settings** — every file in the list opens its own panel; "Apply to all video / photos / audio" copies the settings to the others; defaults for new files live in Settings.
- **Drag and drop** — files and folders, several at once; `Ctrl+O` opens the file dialog, `Ctrl+Enter` starts.
- **Outputs** — next to the source as `<name>_forge.<ext>` or into one folder; "Show in folder", "Open", "Run again", optional folder opening and a sound when a batch finishes.
- **Self-update** — checks GitHub Releases on launch and on the interval in Settings; Download and Restart from the version label; automatic download as an option.
- **Portable** — everything the app writes lives in `media-forge_data\` next to the exe; ffmpeg is taken from `PATH` or downloaded once into that folder.
